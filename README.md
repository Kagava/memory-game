# Описание

🎮 Механика игры
Цель: Найти все совпадающие пары карточек на игровом поле.
Процесс: Игрок открывает по две карточки за один ход. Если эмодзи на них совпадают, пара остаётся открытой и засчитывается в прогресс. Если не совпадают, карточки снова переворачиваются.
Всего пар: 8 (16 карточек на поле).
🖥️ Интерфейс
Счётчик ходов («Ход»): показывает, сколько попыток сделал игрок.
Прогресс («Верные пары»): отображает количество найденных пар из 8 возможных.
Игровое поле: сетка карточек, в качестве изображений на которых используются популярные эмодзи (😀, 👽, 🥵, 🐷, 🙈, 💀, 👾, 🥶).
💻 Техническая часть
Судя по домену github.io, это статический веб-проект, созданный с использованием базовых веб-технологий: HTML, CSS и JavaScript.
